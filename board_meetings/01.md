## Onboarding projects

- What do projects need from Astrolicious?
  - Private channel
  - Optional public channel with free conversations
  - Optional threaded public channel (using needle)
  - Optional support channel (forum channel)
- How to onboard?
  - Using issue templates on the `dotenv` repo
  - Discussion about onboarding on the public issue
- Domain offering
  - An `A`/`AAAA` record on `<project>.astrolicious.dev` (preferred)
  - A `CNAME` record on `<project>.astrolicious.dev`
  - Nested subdomains might be possible on very specific cases, but only after careful deliberation
- Hosting offering (postponned until further discussion)
  - Can be managed by Astrolicious, but require Starlight and will be hosted on Cloudflare

## Metrics

Metrics are self-reported on PRs to `astrolicious.dev` repo.

## Roles (Discord and GitHub)

Discord:

- Astro Core
- Astro Maintainer
- Stewards
- Mastermind/Board
- Content creator (contributors to Astro Tips and authors of external content)
  - Access to a private channel for community authors and Astro maintainers+
- Mods
- Supporter/Enthusiast (Default)
- <project> Maintainer (per project)
- Notify <project> (per project - user opt-in)

GitHub:

- Stewards
- Mastermind/Board
- No more per-project teams
  - Initial maintainers will be given Admin rights to the repo
  - New maintainers/admins can be added by existing repo admins
